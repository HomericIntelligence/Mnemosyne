# Notes: pipeline-artifact-embedding-verification

Supporting evidence from the source session (generalized; no internal identifiers).

## Defect anatomy

An HTML-to-PDF step rewrote Markdown image references from the figure format used on the
web page (`.svg`) to the raster format used for print (`.png`):

```python
html = re.sub(r'(src="assets/[^"]+)\.svg"', r"\1.png\"", html)
```

In a Python raw string, the sequence `\"` inside a double-quoted raw literal is kept as
two characters (backslash, quote). The replacement value was therefore `\1.png\"`, and
every emitted tag pointed at `assets/figNN.png\` — a path that resolves to nothing. The
renderer dropped all 17 figures without a warning, on every build, for weeks. Every
previously shipped PDF was affected the same way, which shows that "it built before" is
not evidence of content.

## Why the first diagnosis was wrong

The operator counted image XObject signatures in the PDF:

```python
data = open("report.pdf", "rb").read()
found = 0
for m in re.finditer(rb"stream\r?\n(.*?)endstream", data, re.S):
    try:
        text = zlib.decompress(m.group(1))
    except Exception:
        text = m.group(1)
    found += text.count(b"/Subtype /Image")
```

Result: 0 — for BOTH the historical broken artifact and a fresh artifact that did embed
the images. The PDF writer (WeasyPrint/pydyf generation in use) serializes image
dictionaries inside compressed object streams in a form the literal
`/Subtype /Image` never matches byte-for-byte. The test could not discriminate states,
so it supported both "missing" and "embedded". Two wrong next moves followed it:
suspect the base-URL path resolution (behavior-neutral change), and suspect the
renderer version.

## The probes that did discriminate

1. **Loader spy**: wrap `PIL.Image.open` with a counter that records the file name,
   then call the build's `write_pdf`. Working build: one recorded open per figure PNG
   (17). Broken build: zero. This was the decisive single probe.
2. **Size delta**: `wc -c` on the artifact. Broken line of builds: 31–44 KB regardless
   of figure count. Fixed build: 972 KB for 17 figures at 150 dpi, consistent with the
   (re)compressed inputs. A "fix" that moves the artifact size by ~0 proved itself wrong
   instantly.
3. **Direct string check**: print the exact rewritten tag
   (`<img ... src="assets/fig01_release_cadence.png\" />`) — the trailing `\` was
   visible immediately once the transform's *output* was inspected rather than its
   input.

## Regression test that ships with the fix

```python
def test_png_figure_refs_swaps_extension_without_stray_backslash():
    html = '<img alt="x" src="assets/fig01.svg" />'
    out = render._png_figure_refs(html)
    assert 'src="assets/fig01.png"' in out
    assert ".svg" not in out
    assert "\\" not in out
```

The transform was also extracted into a small pure function so the test needs no
renderer, container, or network.
