## Evidence Boundary

Current-tree reads established the legacy dispatch structure, blocking sleep behavior, shared parser,
real symbol home, extraction candidate, and frozen coverage-omit membership. Those facts grounded the
design but did not verify the sibling APIs.

The sibling coordinator, queue, pool, stage, route, config, fake, and tick-order contracts came only
from issue bodies. The revised plan addressed review findings, but no code, build, or CI execution
followed. These cases therefore remain unverified.
