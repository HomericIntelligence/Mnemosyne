# Notes: author-response-provable-authority-binding

Privacy-safe supporting evidence. Source: a same-day multi-lane campaign of chain-verified plan/review exchanges on a shared forge (details generalized).

## Evidence synthesis

- **Adapter acceptance path (the core case).** A required finding demanded that a plan name the reviewed artifact accepting an isolation adapter for a gated host integration. The artifact did not exist anywhere. The author's enumeration proof, later re-run by the reviewer to identical results: the package manifest registers no entry-point group for that adapter family (clean miss); registration symbols appear only in the runtime module and two unit-test fakes; the most plausible sibling issue is scoped to a different harness family. The response bound a named delivery issue (conditionally `state:plan-go`) plus its contract child, quoted the loader and fail-closed require-check with file line pins at the pinned base, named an admission checkpoint that succeeds only when exactly one delivery is installed, and recorded verbatim that nothing exists at the base, keeping the gate closed until delivery. The reviewer independently fetched both issues from the forge, verified titles, parent links, labels, and acceptance criteria, confirmed the absence enumeration, and judged the future-delivery contract closing. Verdict: GO.
- **Substitute arm with verbatim authority.** A finding's closure offered two arms; the author chose the approved-substitute arm, quoted the authority text ("where practical") from the parent issue's acceptance section, pinned the approved not-applicable disposition record and its manifest default, and named both verification commands (completion gate and comparison gate). The reviewer traced the completion gate through the run-verifier into the comparison check and confirmed that any disposition drifted from the reviewed record raises — the substitute fails closed. GO.
- **Runner contract restatement (no weakening).** A major finding showed a plan's clean-preflight could never pass on the only machine matching its description (operator-owned, forbidden to clean). The author recounted the workflow's runner values independently (40 pinned-line values including one matrix variable, zero self-hosted targets; a grand total of 42 including a lint fixture), named the owning operator group and label, defined an in-band fail-closed preflight with an attestation artifact, and re-executed all seven criteria downstream with textually unchanged commands. The reviewer recounted (resolving a review-side 43-versus-40 precision miss), diffed both revisions, and found no disguised weakening. GO.
- **ADR clause re-map.** An acceptance clause in a superseded architecture record named a gate test that exists only in that record's text. The author picked the closure's re-map arm: intent preserved as a non-skipping, fail-closed bound-identity gate with executable anchors, plus a planned superseded-in-part index marking. Reviewer verified the named test's sole reference is the record text and that the re-map's anchors exist. GO.
- **Stale reconciliation rebind.** A plan's reconciliation with a competing boundary design predated that design's approval (plan-GO with a numbered architecture record). The author re-bound to the accepted record with exact citations and named the single host-control-service owner. GO.
- **Self-disclosures.** One author disclosed that an incidental default flag meant its prior hook revision would have fired anyway (resolved explicit-choke anyway); another disclosed a digest-form mismatch hypothesis that reviewers later resolved as an analyst error (the digest binds the review's own visible content, not the plan body). Neither hurt the exchange; both are cited by reviewers as positive signals.

## Generalization limits

- The doctrine governs *response* content. Severity decisions remain the exchange contract's: a provable-authority answer can still receive NO-GO if the bound delivery path is judged unexecutable.
- Absence enumeration cannot prove global non-existence outside the enumerated surfaces; state the search surface in the evidence and let the reviewer extend it.
- Verbatim authority quotes and issue identifiers must be fetchable by the reviewer; if the binding record lives somewhere credentials cannot reach, record the full text in the evidence.
